JUNGLE OS

Live performance with both instruments

Break Surgeon (A) on one mixer channel, Abyss Engine (B) on another. The mixer's model is not confirmed: nothing here assumes it has MIDI, effects, sends or a particular routing. Each FM-1's output is stereo (headphone jack); A's signal is mono-compatible by design (the drum bus is mono), B's sub and bass are centred.

Before the set

  1. Link (optional): see docs/architecture/link-protocol.md for the routes; set the same LINK CH on both. On A: SYSTEM K4 SYNC OUT = ON, CLOCK = INT. On B: FOLLOW = LINK. Without a link: same BPM on both, PLAY together, SOLO DUCK on B.
  2. Gain: MASTER on both at about 3/4. A's ceiling is −0.5 dBFS with typical peaks around −2.5 dBFS (renders: peak 0.75 at MASTER-equivalent 0.9); B peaks similar with more RMS (bass). Set the mixer channels so B's sub sits under A's kick, not on top: start with B's channel ~3 dB below A's and adjust by ear on the actual PA.
  3. Low end: B's sub lives at 36–72 Hz, mono. If the PA has a crossover, check the sub on it before the set (docs/development/testing.md, listening checklist).
  4. Save both (stopped).

Transitions that work

  • On the bar, every time: scenes and pattern changes are quantized (SCENE K1); press anywhere in the bar before.
  • Fill into a scene: FILL first, the scene on the same bar: the fill ends with an IMPACT hit on the downbeat.
  • Safe exit: REC (RETURN) on either: A back to the stable groove at the next bar, B onto a curated node.
  • Panic: SEL + PLAY on either device stops and silences it.

Gain staging inside the instruments

  • A: PRESSURE adds density, not level (it trims as it pushes). Watch the FX page's peak meter: red is the ceiling.
  • B: BITE and DIRT are trimmed; WEIGHT changes only the sub. The guard catches show on the FX page: occasional is fine, constant means MASTER or PRESSURE is too high.
